Tengja rauntíma-gagnagrunn

Til að allir símar fái spurningar, læsi svörum og uppfæri stigatöfluna í rauntíma á GitHub Pages þarftu eina ókeypis Firebase Realtime Database slóð:

  1. Farðu á console.firebase.google.com og búðu til nýtt verkefni (ókeypis).
  2. Veldu Build → Realtime Database → Create Database og veldu Start in test mode.
  3. Afritaðu slóðina sem birtist efst (t.d. https://mitt-quiz-default-rtdb.europe-west1.firebasedatabase.app) og límdu hana hér fyrir neðan.
  4. Smelltu á Vista & Afrita kóða fyrir GitHub og límdu inn í index.html á GitHub – þá þarftu aldrei að opna Firebase aftur!

Öryggisathugasemd: „Test mode“ leyfir hverjum sem er að lesa og skrifa í gagnagrunninn. Notaðu hann aðeins fyrir þennan leik, ekki geyma persónuupplýsingar þar og farðu yfir reglurnar eftir leikinn. Firebase lokar sjálfgefið fyrir aðgang þegar prufutímabilið rennur út ef reglunum er ekki breytt.
